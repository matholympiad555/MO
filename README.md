# Banglar Math Olympiad (বাংলার ম্যাথ অলিম্পিয়াড) 🏆

> **যুক্তির শক্তিতে এগিয়ে চলো — গণিতকে ভয় নয়, যুক্তি দিয়ে গণিতকে জয় করো!**

একটি আধুনিক, ইন্টারেক্টিভ এবং পূর্ণাঙ্গ প্ল্যাটফর্ম যা প্রাইমারি ও জুনিয়র গণিত অলিম্পিয়াড শিক্ষার্থীদের প্রস্তুতি, অনলাইন মক টেস্ট, সার্বক্ষণিক প্রশ্ন সমাধান এবং কোর্স বুকিংয়ের জন্য তৈরি।

---

## 🚀 প্রধান ফিচারসমূহ (Key Features)

### ১. ল্যান্ডিং পেজ ও কোর্স বিবরণী (Course Showcase)
- প্রাইমারি গণিত অলিম্পিয়াড প্রস্তুতি কোর্স ২০২৬ এর পূর্ণাঙ্গ বিবরণ।
- কোর্স ফিচার: ৭+ ঘণ্টার ক্লাস, রেকর্ডেড লেকচার, পূর্ণাঙ্গ মক টেস্ট, অলিম্পিয়াডধর্মী গাণিতিক সমস্যার অনুশীলন ও বিশ্লেষণী দক্ষতা চর্চা।
- মাত্র ১৯৯ টাকা প্রি-বুকিং অফার ও বিকাশ পেমেন্ট ইন্টিগ্রেশন।

### ২. অনলাইন মক টেস্ট ইঞ্জিন (Interactive Mock Test Engine)
- **রিয়েল-টাইম কাউন্টডাউন টাইমার:** আসল অলিম্পিয়াড পরীক্ষার আদলে নির্ধারিত সময়ের ভেতর টেস্ট দেওয়ার সুবিধা।
- **ইন্টারেক্টিভ টেস্ট রানার:** প্রশ্ন প্যালেট (Question Grid), ফ্ল্যাগিং (Mark for Review), এবং ক/খ/গ/ঘ অপশন নির্বাচন।
- **স্বয়ংক্রিয় ও তাৎক্ষণিক ফলাফল:** সাবমিটের সাথে সাথে স্কোর, সঠিকতার হার এবং শতকরা নম্বর প্রদর্শন।
- **ধাপে ধাপে অলিম্পিয়াড ব্যাখ্যা:** প্রতিটি প্রশ্নের সঠিক উত্তর এবং অলিম্পিয়াড শর্টকাট ট্রিকস সহ বিশদ সমাধান।

### ৩. ২৪/৭ প্রশ্নোত্তর ফোরাম (Community & Mentor Q&A)
- গণিতের যেকোনো সমস্যা বা কনসেপ্ট নিয়ে প্রশ্ন পোস্ট করার সুবিধা।
- ক্যাটাগরি ও টপিক ফিল্টারিং (সংখ্যাতত্ত্ব, জ্যামিতি, প্যাটার্ন ও যুক্তি, গণনাতত্ত্ব, সাধারণ)।
- মেন্টর ও সহপাঠীদের সমাধান দেওয়ার ব্যবস্থা এবং **মেন্টর ভেরিফাইড ব্যাজ**।
- লাইভ আপভোট (Upvote) সিস্টেম।

### ৪. প্রি-বুকিং ও পেমেন্ট ভেরিফিকেশন (bKash Pre-Booking & Verification)
- bKash ট্রানজেকশন আইডি (TrxID) দিয়ে সহজে প্রি-বুকিং ফর্ম সাবমিট।
- **লাইভ স্ট্যাটাস ট্র্যাকার (`/status`):** শিক্ষার্থী যেকোনো সময় মোবাইল নম্বর বা TrxID দিয়ে তার বুকিং ভেরিফিকেশন স্ট্যাটাস (পেন্ডিং, অনুমোদিত বা বাতিল) ট্র্যাক করতে পারে।

### ৫. অ্যাডমিন ম্যানেজমেন্ট ড্যাশবোর্ড (`/admin`)
- পেমেন্ট ও প্রি-বুকিং তালিকা ব্যবস্থাপনা (১-ক্লিকে Verify বা Reject করার সুবিধা)।
- মোট রাজস্ব, ভেরিফাইড শিক্ষার্থী সংখ্যা, মক টেস্ট অংশগ্রহণ এবং Q&A পরিসংখ্যান।
- সুরক্ষিত অ্যাডমিন অ্যাক্সেস (ডিফল্ট পাসকোড: `bmo2026admin`)।

## 🛠️ টেক স্ট্যাক (Tech Stack)

- **ফ্রেমওয়ার্ক:** [Next.js 16](https://nextjs.org/) (Turbopack, App Router)
- **লাইব্রেরি:** [React 19](https://react.dev/)
- **স্টাইলিং:** [Tailwind CSS v4](https://tailwindcss.com/)
- **আইকন:** [@phosphor-icons/react](https://phosphoricons.com/)
- **টাইপসেফটি:** [TypeScript 5](https://www.typescriptlang.org/)
- **ডাটাবেজ ও স্টোরেজ:** Supabase Schema (`supabase/schema.sql`) + হাইব্রিড লোকাল পারসিস্টেন্ট স্টোর (জিরো-কনফিগারে তাৎক্ষণিক ব্যবহারের উপযোগী)

## 💻 লোকাল ডেভেলপমেন্ট (Running Locally)

১. ডিপেন্ডেন্সি ইনস্টল করুন:
```bash
pnpm install
```

২. ডেভেলপমেন্ট সার্ভার চালু করুন:
```bash
pnpm run dev
```

৩. ব্রাউজারে ওপেন করুন:
- ওয়েবসাইট: `http://localhost:3000`
- মক টেস্ট: `http://localhost:3000/mock-tests`
- প্রশ্নোত্তর (Q&A): `http://localhost:3000/qa`
- বুকিং স্ট্যাটাস: `http://localhost:3000/status`
- অ্যাডমিন ড্যাশবোর্ড: `http://localhost:3000/admin` (পাসকোড: `bmo2026admin`)
